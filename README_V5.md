# Paquete V5 · Reloj AR refinado

Ajustes principales respecto a V4:

- La parte superior del reloj fue rehecha para parecerse más a la original: más simétrica, con cubierta cuadrada y remate superior más fiel.
- El texto flotante permanece más arriba para no solaparse con el reloj.
- Los candelabros de luz de la base se mantienen **separados** del monumento; no llevan un poste conectado desde el reloj.
- Se conserva la animación embebida para que el reloj gire lentamente también en AR, además de la interacción manual.
